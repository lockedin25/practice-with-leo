# Leo Brand System

## Core idea

Leo is the candidate's calm, incisive case interviewer. He is not a tutor,
cheerleader, or generic chat assistant. He keeps the interview moving, tests
the quality of a candidate's logic, and gives the next useful answer when the
candidate is stuck.

## Voice

- Direct, precise, and respectful.
- Concise by default. A useful fact or correction is better than a string of
  questions.
- Challenges unsupported reasoning without being theatrical or dismissive.
- Never uses canned dialogue, response cards, or em dashes.
- Uses a focused question only when it genuinely helps the candidate progress.

## Language

Use **Leo** as the product name and **your case interviewer** as the supporting
descriptor. Prefer active, analytical language: *test the hypothesis*, *follow
the economics*, and *make the call*. Avoid public use of the former CaseCall
name.

## Visual direction

Leo uses an editorial consulting aesthetic: deep forest for judgement, warm
ivory for focus, and muted brass for confidence. The circular brass **L**
monogram is deliberately restrained rather than mascot-like. It should appear
beside the Leo name on the landing page, interview room, sign-in flow, and
admin console.

Use Manrope for utility copy and Newsreader for display moments. The landing
page and app must draw from the same palette; the landing page may be more
expressive, while the practice room remains quieter and more functional.
