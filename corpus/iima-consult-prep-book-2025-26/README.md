## How to use this corpus

This is a **structured source corpus**, not a single giant prompt. Each case has a candidate opening brief, an ordered facilitator script, facilitator-only approach material, and a runtime-QA status. A runtime should select one package, add explicit fact-release gates, and give the interviewer only the current-stage context.
