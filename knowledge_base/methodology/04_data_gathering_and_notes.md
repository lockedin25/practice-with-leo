# Data Gathering, Note-Taking Architecture & Commercial Math

## 1. Executive Summary & The Physicality of Casing

In high-stakes MBB case interviews, cognitive overload is the single largest driver of arithmetic errors and structural confusion. Candidates who write notes randomly across scrap paper quickly lose track of assumptions, misplace baseline figures, and stumble during final synthesis.

Top consultants treat their notepad as an **external cognitive hard drive**. A disciplined, standardized note layout frees working memory for strategic reasoning, makes multi-step calculations visually transparent, and allows the candidate (or interviewer glancing at the page) to instantly locate any metric or insight.

```
+------------------------------------------------------------------------------------+
|                         THE 3-ZONE CONSULTING PAGE LAYOUT                          |
+------------------------------------------------------------------------------------+
| [ ZONE 1: CASE FACTS & OBJECTIVES (Top 20% of Page) ]                              |
| • Client Name, Core Industry & Business Model                                      |
| • Quantified Target, Metric Baseline & Time Horizon                                |
| • Hard Constraints & Strategic Boundary Conditions                                 |
+------------------------------------------------------------------------------------+
| [ ZONE 2: STRUCTURE & QUANTITATIVE WORKBENCH (Middle 60% of Page) ]                |
| • MECE Issue Trees & Mathematical Equations                                        |
| • Data Tables (Pre vs. Post, Segment Splits, Competitor Benchmarks)                |
| • Step-by-Step Arithmetic Operations with Explicit Units                           |
+------------------------------------------------------------------------------------+
| [ ZONE 3: KEY INSIGHTS & SYNTHESIS RUNWAY (Bottom 20% of Page) ]                   |
| • Major Breakthroughs & Isolated Root Causes ("So What?" bullet points)            |
| • Core Strategic Recommendations & Action Levers                                   |
| • Highlighted Risks & Unresolved Trade-offs                                        |
+------------------------------------------------------------------------------------+
```

## 3. Structured Tabular Data Tracking

When an interviewer provides a dense set of figures, never write them in freeform text. Immediately convert unstructured data into **Comparative Structured Tables**.

### The Standard 4-Column Business Diagnostic Table

```
┌─────────────────┬──────────────┬──────────────┬──────────────┬──────────────┐
│ Operational     │ Base Year    │ Current Year │ Absolute     │ Percentage   │
│ Metric          │ (Year 0)     │ (Year 1)     │ Variance (Δ) │ Variance (%) │
├─────────────────┼──────────────┼──────────────┼──────────────┼──────────────┤
│ Volume (Units)  │ 1,000,000    │ 850,000      │ -150,000     │ -15.0%       │
│ Realized Price  │ $120.00      │ $120.00      │ $0.00        │ 0.0%         │
│ Total Revenue   │ $120.0M      │ $102.0M      │ -$18.0M      │ -15.0%       │
│ Variable Cost   │ $60.0M ($60) │ $55.25M ($65)│ -$4.75M      │ +8.3% / unit │
│ Fixed Cost      │ $30.0M       │ $32.0M       │ +$2.0M       │ +6.7%        │
│ Operating Profit│ $30.0M       │ $14.75M      │ -$15.25M     │ -50.8%       │
│ Margin (%)      │ 25.0%        │ 14.5%        │ -10.5% pts   │ -42.0%       │
└─────────────────┴──────────────┴──────────────┴──────────────┴──────────────┘
```

### Key Advantages of Tabular Organization
1. **Immediate Variance Isolation:** Instantly shows whether volume, price, variable cost per unit, or fixed overhead drove the margin collapse.
2. **Eliminates Double-Counting:** Every dollar and percentage point is anchored to its accounting relationship.
3. **Executive Visual Aid:** The interviewer can track your calculations in real time.

## 4. Arithmetic Sanity-Checking & Commercial Math Discipline

In consulting, calculation accuracy is non-negotiable. However, mathematical competence in casing is not about performing complex calculus; it is about executing **high-speed arithmetic with zero errors and strong commercial intuition**.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    THE 4 ARITHMETIC SANITY-CHECKING RULES                   │
├─────────────────────────────────────────────────────────────────────────────┤
│ 1. EXPLICIT UNIT TRACKING:                                                  │
│    Never write naked numbers. Always write units ($M, €/kg, km, %, basis    │
│    points, hours). Carry units through every step of multiplication/division│
│    (e.g., $ / ton * tons = $).                                              │
├─────────────────────────────────────────────────────────────────────────────┤
│ 2. SCIENTIFIC NOTATION & ZERO MANAGEMENT:                                   │
│    Manage large numbers using powers of 10 or metric prefixes:              │
│    • 1 Million = $10^6$ (M)                                                 │
│    • 1 Billion = $10^9$ (B)                                                 │
│    • Multiplying $10^6$ by $10^3$ = $10^9$ (Million * Thousand = Billion)   │
│    • Rule: Never write out 8 trailing zeros on paper; use M and B shorthand.│
├─────────────────────────────────────────────────────────────────────────────┤
│ 3. PERCENTAGE MATH & GROWTH COMPOUNDING SHORTCUTS:                           │
│    • Fraction Equivalencies: 1/6 = 16.7%, 1/7 = 14.3%, 1/8 = 12.5%,         │
│      1/12 = 8.33%, 1/15 = 6.67%.                                            │
│    • Rule of 72: Doubling time = 72 / (Annual Growth Rate %).               │
│      (e.g., at 8% CAGR, market doubles in 72 / 8 = 9 years).                │
├─────────────────────────────────────────────────────────────────────────────┤
│ 4. ORDER-OF-MAGNITUDE COMMERCIAL SANITY CHECK:                              │
│    Before stating a final number, pause for 2 seconds and ask:              │
│    "Does this number make commercial sense in the real economy?"            │
│    (e.g., Did my calculation just imply that every person in the UK eats    │
│     500 pizzas a day? If yes, find the misplaced decimal immediately).      │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 5. Verbalizing Math: The "Think-Out-Loud" Protocol

Dead silence for 90 seconds while performing arithmetic makes interviewers anxious and prevents them from catching minor transcription errors. Top candidates employ the **Think-Out-Loud Protocol**, turning math into a collaborative executive briefing.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    THE 4-STEP "THINK-OUT-LOUD" PROTOCOL                     │
├─────────────────────────────────────────────────────────────────────────────┤
│ STEP 1: STATE THE ROADMAP & FORMULA FIRST                                   │
│ "To calculate our annual fuel cost savings, I will multiply our total fleet │
│ mileage by our fuel efficiency improvement, and then multiply by the average│
│ diesel price of $1.50 per liter."                                           │
├─────────────────────────────────────────────────────────────────────────────┤
│ STEP 2: STATE THE INPUTS & INITIAL VALUES                                   │
│ "We have 500 trucks traveling 100,000 km per year, giving us 50 million     │
│ total fleet kilometers."                                                    │
├─────────────────────────────────────────────────────────────────────────────┤
│ STEP 3: PERFORM THE STEP-BY-STEP CALCULATION AUDIBLY                        │
│ "At our baseline efficiency of 0.40 liters per km, total fuel consumed is   │
│ 50M * 0.40 = 20 million liters. With our 10% aerodynamic routing savings,   │
│ we save 2.0 million liters annually."                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│ STEP 4: STATE THE FINAL RESULT WITH THE "SO WHAT?"                          │
│ "Multiplying 2.0M liters saved by $1.50 per liter yields $3.0M in annual    │
│ EBITDA expansion. This covers 60% of our $5.0M profit recovery target."     │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 6. Handling Unexpected Data Twists, Conflicts, and Missing Data

During casing interviews, candidates often encounter ambiguous, contradictory, or missing data points. How you react under uncertainty is heavily weighted in the evaluation.

```
┌──────────────────────────────────────────────────────────────────────────────┐
│                    DATA TWIST SCENARIOS & RECOVERY PROTOCOLS                 │
├──────────────────────────┬───────────────────────────────────────────────────┤
│ SCENARIO                 │ RECOMMENDED ACTION & VERBAL PHRASING              │
├──────────────────────────┼───────────────────────────────────────────────────┤
│ 1. Missing Data Point    │ State the required variable, make a reasonable,   │
│    (Interviewer does not │ grounded assumption, and ask for validation:      │
│     volunteer the number)│ "To calculate the market size, we need the average│
│                          │ replacement cycle. In automotive, 7–8 years is    │
│                          │ standard. Would you like me to use 8 years?"      │
├──────────────────────────┼───────────────────────────────────────────────────┤
│ 2. Contradictory Data    │ Highlight the variance professionally without     │
│    (Two data points      │ being confrontational:                            │
│     appear in conflict)  │ "Looking at Exhibit 1, customer churn is 12%, but │
│                          │ total revenue in Table 2 expanded 15%. This       │
│                          │ implies our expansion revenue per existing account│
│                          │ is outpacing logo churn. Let's verify that."      │

│ 3. Sudden Negative Math  │ Re-anchor quickly, find the commercial meaning:   │
```

## 7. Tactical Data Gathering Checklist

- [ ] **Is my page divided into 3 distinct zones?** (Header/Scope, Working calculations, Key takeaways).
- [ ] **Did I convert multi-variable data into a clean 2x2 or diagnostic table?**
- [ ] **Are all numbers annotated with their proper units ($M, %, bps, tons)?**
- [ ] **Did I state my calculation roadmap before writing numbers?**
- [ ] **Did I avoid dead silence by verbalizing key calculation milestones?**
- [ ] **Did I execute an order-of-magnitude sanity check before declaring the answer?**
- [ ] **Did I extract the strategic "So What?" immediately after calculating the number?**
